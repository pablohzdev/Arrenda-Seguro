# Arrenda-Seguro
Sistema de Análisis Léxico-Sintáctico para la Detección Automatizada de Cláusulas Abusivas en Contratos de Arrendamiento

### 🎨 Frontend: Configuración del Frontend

La interfaz visual consumirá la API que acabamos de levantar.

**`. Instalar dependencias de Node:**

```bash
pnpm install
```

**1. Ejecutar entorno de desarrollo:**

```bash
pnpm dev
```

> El navegador abrirá la aplicación en: `http://localhost:5173`
